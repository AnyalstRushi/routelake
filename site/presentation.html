Correctness is built
into the behavior.

≠

Identity is protected

Conflicting reuse of a batch ID is rejected.

↶

Transactions roll back

⇥

≋

Reconciliation checks

Batch arithmetic and Gold-vs-Silver aggregates are checked.

⌁

Stable routing

Feasibility is exposed; hysteresis resists flip-flopping.

10 / THE SPEND BRAIN

Median first.
Outliers second.

ANOMALY.PY / CONCEPTSIMPLIFIED
01def robust_z_score(value, history):02 center = median(history)03 deviations = [abs(x - center) for x in history]04 mad = median(deviations)05 if mad == 0:06 return None07 return 0.6745 * (value - center) / mad
ROBUST BASELINE
MAD

Median absolute deviation

A median-centered measure of spread. A large robust z-score marks a point that sits far from its typical baseline.

The code is a teaching sketch, not a complete production implementation.
