# Code of Conduct

RouteLake aims to be a welcoming, respectful and constructive project. Participants are expected to be considerate, use inclusive language, accept good-faith feedback, and focus criticism on ideas and code rather than people.

Harassment, discrimination, personal attacks, doxxing and disruptive behavior are not acceptable. Project maintainers may remove content or restrict participation when necessary to protect the community.

For concerns, contact the repository maintainer through the contact method listed on the GitHub profile. Please do not report security vulnerabilities publicly; use `SECURITY.md`.
