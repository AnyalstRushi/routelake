# Open-source readiness checklist

- [x] README with purpose, quickstart, architecture and maturity notes.
- [x] Existing CI workflow (Python 3.10–3.13 matrix).
- [x] Contribution guidance.
- [x] Code of conduct.
- [x] Security reporting guidance.
- [x] Root MIT license confirmed in the repository.
- [ ] Enable Dependabot alerts, secret scanning and push protection in repository settings.
- [ ] Enable private vulnerability reporting if appropriate.
- [ ] Configure branch protection and required CI checks.
- [ ] Enable GitHub Pages with GitHub Actions as the deployment source.

This checklist does not imply that the unchecked settings have been enabled.
